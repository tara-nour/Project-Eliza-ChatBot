# Ethics impact evaluation
1. Identification des risques éthiques

### Risques majeurs
**L'effet ELIZA dans le domaine de la santé** C'est le risque le plus critique dans ce secteur. Un utilisateur anxieux ou vulnérable pourrait développer une relation de confiance excessive avec le chatbot, le percevant comme un vrai professionnel de santé. Cela peut mener à :

- Des décisions médicales basées sur les réponses du chatbot
- Un retard à consulter un vrai médecin
- Une dépendance émotionnelle au bot (chatbot psychosis)

**Données de santé ultra-sensibles**: Les données échangées (symptômes, traitements, rendez-vous) sont parmi les plus sensibles qui existent. Les risques sont :

- Fuite ou revente de données personnelles de santé
- Non-conformité au **RGPD** (particulièrement strict sur les données de santé en Europe)
- Utilisation des données à des fins commerciales non consenties
